# ENCORE — 탭 사운드 공연장 (Chrome 확장프로그램)

지금 보고 있는 탭에서 나오는 소리를 받아, 내 컴퓨터 안에서 스타디움 공연장 사운드로 바꿉니다. 유튜브, 음악 사이트, 영상 사이트 등 웹페이지에서 재생되는 소리라면 무엇이든 연결할 수 있습니다. 별도의 음원 파일이나 서버는 필요하지 않습니다.

## 설치

1. PC용 Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `manifest.json` 파일이 들어 있는 폴더를 선택합니다. 이미 설치되어 있었다면 확장프로그램 카드의 **새로고침(↻)** 버튼만 누르면 됩니다.
5. 크롬의 퍼즐 모양 메뉴에서 **ENCORE**를 고정하면 편합니다.

Chrome 116 이상 데스크톱 버전이 필요합니다.

## 듣기

1. 아무 웹페이지에서 음악이나 영상을 재생합니다.
2. 그 탭을 보고 있는 상태에서 상단 **ENCORE 아이콘**을 클릭합니다.
3. 패널 오른쪽 위에 **탭 오디오 연결됨**이 보이면 연결된 것입니다. 옆의 **해제**를 누르면 원래 소리로 돌아갑니다.
4. 원형 다이얼을 돌리면 고개 방향이 바뀝니다. 위쪽 호가 무대예요. 방향키로도 5°씩(Shift는 30°) 돌릴 수 있습니다.
5. **공연장 사운드** 스위치로 효과를 켜고 끕니다.
6. 보컬 선명도·울림·관객 배경 소리·방향감·볼륨을 조절합니다.

## 소리 구성

- **보컬:** 가운데(보컬이 있는 자리) 소리만 골라 85ms 뒤에 밝고 긴 잔향을 붙입니다. 말은 또렷하게, 뒤로는 길게 울립니다. 보컬 선명도를 올리면 2.7–5kHz가 앞으로 나옵니다.
- **스타디움:** 가상의 메인·딜레이 스피커, 전체 울림, 뒤쪽 관중석 반사음이 더해집니다.
- **관객 배경 소리:** 음악이 나오는 동안 수만 명이 웅성거리는 소리가 천천히 커졌다 작아지며 깔리고, 관중석 여기저기서 이따금 환호나 박수가 들립니다. 음악이 멈췄다가 다시 시작되면 크게 환호합니다. 0으로 하면 모두 꺼집니다.

## 데이터와 권한

오디오는 로컬 Web Audio 그래프에서만 처리합니다. 녹음, 파일 저장, 업로드, 로그인 기능은 없고 마이크 권한도 요청하지 않습니다. 탭 전체의 소리를 받으므로 말소리·광고 등도 함께 처리됩니다. 사이트나 브라우저가 오디오 캡처를 제한하면 소리가 들어오지 않을 수 있습니다.

## 문제가 있을 때

- 소리가 안 나면 패널의 **해제**를 누른 뒤 원래 소리가 돌아오는지 확인하세요. 탭을 새로고침하고 아이콘을 다시 눌러 연결할 수도 있습니다.
- 말소리가 너무 울리면 울림을 20–30 정도로 낮추거나 스위치를 꺼서 비교하세요.
- 관객 소리가 너무 크면 관객 배경 소리를 낮추세요. 블루투스 이어폰은 기기 자체 지연이 더해집니다.

## 구조

- `worker.js`: 탭 캡처·세션과 패널 연결
- `offscreen.js` / `audio-engine.js`: 로컬 실시간 오디오 처리
- `pa-system.js`: 가상 스타디움의 스피커 배치와 시간 정렬
- `fonts/`: Pretendard, Big Shoulders Display (SIL OFL 1.1)
- `settings.js`: 설정 기본값과 검증
- `panel.html` / `panel.js` / `panel.css`: 제어 패널

가상의 스타디움과 PA 배치를 사용한 시뮬레이션이며, 실제 공연장 측정값을 사용한 재현은 아닙니다.
